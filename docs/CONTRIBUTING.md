# Contributing

Help improve accuracy, including reporting null and negative results. Open an Issue with:

1. The exact `study_id` / `ingredient_id` (or proposed new distinct ID).
2. A DOI/PMID and primary publication link, not an unverified marketing article.
3. The precise population, intervention, dose, duration and primary outcome.
4. Whether you inspected abstract, full text and registered protocol.
5. Any funding/conflicts, corrections, retractions or overlap with published studies.
6. A suggested edit written in your own words.

For changes to CSVs, keep existing IDs, preserve column order and run `python scripts/validate.py`. Do not add copied article PDFs, copyrighted abstracts or extended excerpts. Health claims for V1 commercial content require **separate regulatory review**; a GitHub pull request never grants authorization to make a claim.

V1 Health is a supplement brand; disclose relevant financial relationships when contributing.
